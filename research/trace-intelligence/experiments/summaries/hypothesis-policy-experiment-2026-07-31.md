# Governed hypothesis policy experiment (2026-07-31)

Two deterministic proposal policies and a no-proposal control were run through
the governed release pipeline on a sealed two-evidence fixture. Both proposal
policies produced one independently verified proposal, visible before source
deletion and invisible after deletion. The no-proposal control produced no
release. The verifier packet excluded generator rationale and the release used
the cited evidence lineage.

This validates policy/control plumbing, authority filtering, and deletion
closure. It does **not** measure hypothesis quality, novelty, human agreement,
held-out task outcomes, memory utility, skill improvement, or causality. The
next required experiment must use blinded adjudication and an independent
changed-system outcome before any proposal policy can be promoted.
