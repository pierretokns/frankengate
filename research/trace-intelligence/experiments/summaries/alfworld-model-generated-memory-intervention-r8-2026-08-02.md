# ALFWorld model-generated durable-memory intervention (r8)

Llama 3.2 generated a procedural memory from a separate successful expert episode, and that memory was injected into three disjoint held-out look-at-light tasks. An expert solved the targets in 10, 29, and 7 steps; the 35-step budget covered all targets.

The no-memory control and generated-memory arm both achieved zero wins through both Ollama harnesses. The generated memory caused 102 invalid actions per harness versus zero for no-memory. Inspection of the external raw receipt shows that the model emitted a malformed XML-like memory rather than a usable procedure. This is direct negative evidence against unverified model-generated memory release and a strong reason to keep promotion gated.
