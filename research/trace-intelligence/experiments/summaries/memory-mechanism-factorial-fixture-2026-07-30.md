# Memory mechanism independent/composed factorial fixture

**Date:** 2026-07-30  
**Status:** deterministic mechanics experiment complete; empirical utility not established

## Design

The harness executes the complete 2^6 factorial over:

1. latest snapshot;
2. bitemporal ledger;
3. exact/structured evidence retrieval;
4. independently verified, immutable released-dream proposal;
5. Memory-Palace-style verbatim state; and
6. independently verified, immutable ReasoningBank-style procedure.

It contains 64 arms: one zero-memory control, six isolation arms, and 57
composed arms. Four authored fixture queries produce 256 blinded decisions.
Every mechanism emits the same item schema with arm-rekeyed opaque references.
The resolver receives no arm, mechanism, gold status, or gold value. The scorer
receives gold only after the decision.

Dream and procedure generation use only frozen pre-query evidence. Separate
generator and verifier identities are enforced through the immutable release
pipeline. Every derived item releases strictly before every query. Three state
labels are independently rederived with the cutoff-safe temporal oracle; the
procedure label is tied to a pre-query successful episode.

## Fixture result

| Isolation arm | Exact decisions |
|---|---:|
| zero memory | 0 / 4 |
| latest snapshot | 2 / 4 |
| bitemporal ledger | 4 / 4 |
| evidence retrieval | 4 / 4 |
| released dream | 1 / 4 |
| verbatim state | 4 / 4 |
| released procedure | 1 / 4 |
| all six mechanisms | 4 / 4 |

Fifty-three composed arms achieved 4/4. The all-mechanism arm did not exceed
the strongest singleton. This is fixture redundancy, not empirical equivalence:
the authored cases deliberately expose a historical lookup, an equal-precedence
conflict, a current-state lookup, and a successful procedure lookup.

## What is established

- complete independent/composed factorial enumeration;
- strict pre-query release enforcement;
- query-independent generator interfaces;
- independent verification and immutable release mechanics;
- uniform blinded packs and post-decision scoring;
- cutoff-safe bitemporal gold reconstruction; and
- conflict-preserving composition without revealing arm labels.

## What is not established

The run contains zero natural-trace units, zero enterprise users, and zero
model calls. It estimates no causal effect. Therefore none of the exact rates
measure memory usefulness, model improvement, user improvement, or enterprise
transfer.

The next utility experiment must falsify or support each mechanism on
predeclared natural-trace and prospective tasks. In particular, temporal memory
must beat latest-only on historical/conflict queries; released dreams and
procedures must beat no-memory and placebo controls on project/time-held-out
verified outcomes; and composed arms must beat their strongest component
without authority, latency, contradiction, or evidence-budget regression.
