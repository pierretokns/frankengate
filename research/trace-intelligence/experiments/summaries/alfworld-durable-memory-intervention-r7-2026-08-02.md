# ALFWorld fair-horizon durable-memory intervention (r7)

A procedural memory was released from a separate successful Mug look-at-light episode and evaluated on three disjoint held-out target tasks (AlarmClock, Book, Bowl). The expert solved the targets in 10, 29, and 7 steps; the 35-step budget therefore covered every target.

Llama 3.2 produced zero wins and zero invalid actions in both no-memory and released-memory arms across both Ollama harnesses. The released memory neither improved task success nor changed protocol validity. This is a valid small durable-memory utility comparison, but it does not establish a general memory effect or authorize promotion.
