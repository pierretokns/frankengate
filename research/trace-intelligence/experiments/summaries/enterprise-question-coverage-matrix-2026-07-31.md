# Enterprise-question coverage matrix (2026-07-31)

The research program is intended to answer questions about personal history,
friction, eval promotion, memory, missing skills, education, cross-user
similarity, and enterprise adaptation. The machine-readable matrix records the
strongest defensible status for each question and the evidence required to
advance it.

The current architecture supports personal-history mechanics and bounded
friction/eval screening. It does **not** yet establish that memory extraction,
skill suggestions, user education, cross-user collaboration, or custom
embeddings improve outcomes. Those remain gated by labels, authorization-safe
cross-user evaluation, family-disjoint interventions, and held-out outcomes.
