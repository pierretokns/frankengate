# FrankenGate performance skills

These skills turn the repository's enterprise-readiness methodology into
repeatable agent workflows:

- `frankengate-load-testing`: direct-vs-gateway, throughput, overload, and soak;
- `frankengate-agent-pressure-testing`: MCP fan-out, cancellation, and mixed agents;
- `frankengate-postgres-capacity-testing`: pool budgets, failover, locks, and WAL;
- `frankengate-kubernetes-resilience`: EKS rollout, scale-in, node, ALB, and HPA drills.

All results must distinguish local contract evidence from live EKS/Aurora
evidence and must use the SLO contract rather than inherited upstream claims.
